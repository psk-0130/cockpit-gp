# Cockpit GP

**실제 F1 서킷을 운전석 시점으로 달리는 1인칭 레이싱 게임.** 웹(Three.js)으로 만든 게임을 안드로이드 앱으로 감싸고, Node.js 서버와 SQLite로 기록·순위·실시간 멀티플레이를 처리합니다.

### ▶ [브라우저에서 바로 플레이](https://psk-0130.github.io/cockpit-gp/)

[게임](https://psk-0130.github.io/cockpit-gp/cockpit-gp.html) · [그래픽 랩](https://psk-0130.github.io/cockpit-gp/graphics-preview.html) · [모델 랩](https://psk-0130.github.io/cockpit-gp/car-model-lab.html)

> 웹 데모에서는 타임 트라이얼과 AI 레이스를 할 수 있습니다. 기록 저장·순위·멀티플레이는 [기록 서버](docs/SETUP.md)를 직접 실행해야 동작합니다.

```
[안드로이드 앱 / 브라우저]                         [리눅스 서버]
 WebView ─ cockpit-gp.html ── HTTP (JSON) ─────▶ server.js ── cockpitgp.db (SQLite)
           Three.js 게임   ── WebSocket (/ws) ──▶  기록 API · 멀티플레이 방
```

## 주요 기능

**레이싱**
- 1인칭 운전석 시점: F1 머신(스티어링 휠 화면, 변속 표시등, 미러)과 GT 스포츠카(원형 계기판, 룸미러)
- 서킷 4곳: 몬차, 스파-프랑코샹, 레드불링, 인터라고스 (실제 랩 길이에 맞춰 축척)
- 타이어 미끄러짐 물리(슬립 각, 마찰원, 하중 이동)와 주행 보조(TC·ABS·자세 제어) 켜고 끄기
- 충돌 시 충격량 교환, 화면 흔들림, 불꽃, 손상(접지력·출력 저하, 핸들 쏠림)
- 스탠딩 스타트(빨간불 5개), 트랙 리밋, 슬립스트림

**모드**
- 타임 트라이얼: 랩 기록 도전, 서킷·차량별 개인 최고 기록
- AI 레이스: 성격(공격성·실수·방어)이 다른 AI 7대와 그리드 출발, 추월·방어·실수
- **실시간 멀티플레이**: 4자리 방 코드로 최대 8명, 서버 시계로 출발 동기화와 완주 판정

**수리 퍼즐 (좌뇌형 · 우뇌형)**
- 손상되면 차를 세우고 두 문제를 풀어 수리: **스트룹 테스트**(글자 색 고르기)와 **다른 하나 찾기**(방향이 다른 화살표)
- 고정 페널티 대신 푸는 시간이 곧 손해. 모든 답의 정답 여부와 반응 시간을 DB에 저장해 유형별 통계로 비교

**기록과 DB**
- 랩·레이스·퍼즐 결과를 서버의 SQLite에 저장, 서킷·차량별 베스트 랩 순위
- 기기 안 기록(모드별·랩별)도 함께 표시

**그래픽 (품질 3단계)**
- 낮음: 가벼운 기본 화면
- 보통: 대기 산란 하늘 셰이더, 환경맵 반사, PBR 노면(노멀·러프니스 맵), ACES 톤 매핑, 서킷별 시간대(한낮·흐림·노을)
- 높음: 실시간 그림자, HDR 블룸, 단면을 이어 만든 곡면 차체(로프트)와 에어포일 날개의 정교한 F1 모델

**모바일**
- 조향 방식 선택: 버튼 / 화면 속 핸들 / 기울기, 진동, 가로 화면 고정

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 게임 | JavaScript, Three.js r128 (WebGL), Web Audio API (엔진음·효과음 합성) |
| 앱 | Android (Java, WebView), Gradle |
| 서버 | Node.js (http, crypto), WebSocket 직접 구현 (외부 패키지 없음) |
| DB | SQLite (`node:sqlite` 또는 `better-sqlite3`) |

이미지·3D 모델 파일 없이 텍스처, 차량, 트랙, 소리를 모두 코드로 생성합니다.

## 빠르게 실행해 보기

- **게임만:** `cockpit-gp.html`을 브라우저로 열면 타임 트라이얼과 AI 레이스를 할 수 있습니다 (인터넷 연결 필요: Three.js CDN).
- **기록 저장·멀티플레이까지:** [`docs/SETUP.md`](docs/SETUP.md)를 따라 `server.js`를 실행하고, 게임의 레이스 설정에서 서버 주소를 입력하세요.

## 알려진 한계

- 서킷 모양은 공개 지도를 보고 손으로 그린 근사치이며, 고저차는 없습니다.
- 멀티플레이에서 플레이어끼리는 충돌 없이 통과합니다.
- 플레이어 이름만으로 기록을 저장하며 로그인(인증)은 아직 없습니다.

## 개발 과정과 AI 활용

이 프로젝트는 AI 코딩 도우미(Anthropic Claude)와 협업해 만들었습니다. 기능 기획과 방향 결정, 테스트와 피드백, 학교 리눅스 서버 구축과 안드로이드 빌드는 직접 진행했고, 코드 작성의 상당 부분은 AI와 함께 했습니다.
